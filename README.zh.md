# 规则管理（Rules manager）

[English](README.md) | 中文

`dsh-rules-manager` 为 DSH 设置面板新增 **规则管理** 分区：列出 DSH 作为工作区指令加载的规则文件，并支持在应用内查看、创建、编辑和删除。

## 管理范围

| 范围 | 文件 |
|---|---|
| 用户全局 | `$DSH_HOME/AGENTS.md`（默认 `~/.dsh/AGENTS.md`） |
| 共享 Agents | `$DSH_AGENTS_HOME/AGENTS.md`（默认 `~/.agents/AGENTS.md`） |
| 项目 | 各项目目录下的 `AGENTS.md`、`CLAUDE.md`、`AGENTS.local.md`、`CLAUDE.local.md` |

项目列表来自 DSH 的工作区注册表。**添加项目** 可把任意已存在的绝对路径加入列表；「移出列表」只删除列表条目，不会改动磁盘上的文件。

## 自动备份与恢复

每次保存、删除、恢复之前，插件都会把当前内容复制到 `$DSH_HOME/rule-backups/`。每个规则文件有独立目录，目录名写明归属（`global-dsh`、`global-agents`，或 `project-<项目名>-<哈希>`）；备份文件名包含本地时间与原文件名，例如 `20261120-171758-123__AGENTS.md.bak`，旁边的 `.json` 记录目标路径、标签、创建时间与原因（`save` / `delete` / `restore`），直接打开文件夹也能看懂是哪份规则、什么时候备份的。

编辑器里的 **备份** 按钮列出当前文件的全部备份，**恢复** 会用选中的备份覆盖当前文件。恢复前会先备份当前内容，所以恢复本身也可以撤回。每个文件保留最新 50 份，更旧的自动清理。

## 使用方式

1. 打开侧边栏的 **设置**，选择 **规则管理**。
2. 在全局卡片上按 **编辑**，或在项目卡片里某个文件行上按 **编辑**。
3. 在文本框中修改后按 **保存**。文件不存在时保存会自动创建（必要时连同父目录）；**删除** 会从磁盘移除该文件。
4. 重启或新建会话后，DSH 才会加载修改后的指令。

## 行为与限制

- 文件读写由插件的 Host 半侧通过单一路由 `/dsh-rules-manager/api/rpc` 完成，浏览器不会拿到文件系统句柄。
- 超过 1 MiB 的规则文件仍会列出，但不能在编辑器中打开。
- 备份失败不会阻止写入，面板会以警告形式提示；超过 4 MiB 的文件写入时不备份。
- 插件只接受上表中的文件名，其它路径会被 Host 拒绝。
- 停用插件只会移除设置分区与路由，规则文件本身不受影响。

## 安装

把包目录作为 DSH bundle 安装（插件 → 添加插件，或 `plugin_manager` 的安装动作），在 bundle 列表中启用 `dsh-rules-manager`，然后重启应用。
